# IPL Franchise Strategy — Business Case Analysis

Consulting-style data analysis on 13 seasons of IPL data to identify 
what drives franchise success and player ROI.

## Tools
Python · Excel · ReportLab · Pandas · Matplotlib

## What's inside
- `notebook/` — Python EDA (win rates, toss analysis, player performance, ROI)
- `excel/` — Financial model with franchise spend vs wins analysis
- `report/` — 5-page consulting PDF report
- `outputs/` — All charts and visualisations

## Key Findings
- Spending more has a negative correlation with win rate among top spenders
- Gujarat Titans: 51 Cr spend, 62.2% win rate — best ROI in IPL history  
- Punjab Kings: 297 Cr spend, 45.5% win rate — worst ROI
- Fielding first wins 53.9% vs batting first 45.4% — clear strategic edge
